# MedLens

MedLens is a modern medical record organizer and laboratory report analyzer powered by Gemini AI and Firebase Firestore.

## Features

- **Patient Profile (`/intake`)**: Structured intake for biometric calibration (vitals, symptoms, medical history, allergies, medications).
- **Report Upload (`/upload`)**: Drag-and-drop diagnostic panel and lab report ingestion (JPG, PNG, WEBP, PDF) with real-time Gemini extraction.
- **Health Records (`/records`)**: Comprehensive health ledger organizing extracted biomarkers with automated reference range and status evaluation.
- **AI Summary (`/summary`)**: Concise, plain-language clinical synthesis generated by Gemini from verified diagnostic panels.

## Technology Stack

- **Framework**: Next.js 16 (App Router)
- **UI & Styling**: React 19, Tailwind CSS 4, Lucide Icons
- **AI & Vision**: `@google/genai` (Gemini 3.6 Flash)
- **Database**: Cloud Firestore
- **Type Safety**: TypeScript 5
